Quiz Platform 🎯

A responsive and interactive Quiz Platform built using HTML, CSS, and JavaScript. The project provides a simple and engaging interface where users can answer quiz questions and interact with the application.

 📸 Preview

![Quiz Platform Preview 1](assets/quiz-preview1.png)

![Quiz Platform Preview 2](assets/quiz-preview2.png)


✨ Features

- 📝 Multiple-choice quiz questions
- 🎯 Interactive answer selection
- 🔄 Dynamic quiz interaction using JavaScript
- 📊 Score/result functionality
- ⏭️ Navigation between questions
- 📱 Responsive user interface
- 🎨 Clean and user-friendly design
- ⚡ Lightweight frontend application

🛠️ Technologies Used

- HTML5 — Used to structure the quiz application
- CSS3 — Used for styling, layouts, and responsive design
- JavaScript — Used to implement quiz functionality and user interactions

🚀 How to Run

1. Clone the Repository

git clone https://github.com/Deepika-Kalluri28/quiz-platform.git

2. Open the Project

cd quiz-platform

3. Run the Application

Open "index.html" in your web browser.

For a better development experience, you can use the Live Server extension in VS Code.

🎮 How to Use

1. Open the Quiz Platform.
2. Read the question displayed on the screen.
3. Select an answer from the available options.
4. Continue through the quiz.
5. Complete the quiz and view your score/result.
